How the pieces fit together

Almost everything in git moves a change through four stages. Learn this shape once, and most commands below are just “move something from one box to the next.”

Merge git merge <branch>

Keeps both histories exactly as they happened, joined by one new merge commit.

Rebase git rebase <branch>

Moves your commits to sit after main's, producing one straight line — no merge commit.
